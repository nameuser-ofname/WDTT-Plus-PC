# WDTT Admin — веб-панель для сервера WDTT

Лёгкая панель управления `wdtt-server`: клиенты, сроки, трафик, настройки,
резервные копии, перезапуск и журнал службы. Один статический бинарник на Go
(без зависимостей и без БД), интерфейс встроен внутрь.

Панель общается с `wdtt-server` через его штатный локальный admin-сокет
(`/run/wdtt/admin.sock`) — тем же способом, что и приложение WDTT Plus и
Telegram-бот. Данные сервера панель сама не правит.

## Установка

Нужно: Linux (amd64/arm64) с systemd и уже установленным `wdtt-server`
(служба `wdtt.service`), root-доступ.

### Вариант 1 — на самом сервере
```bash
scp -r wdtt-admin-panel root@СЕРВЕР:/root/      # или распакуйте zip на сервере
ssh root@СЕРВЕР
cd /root/wdtt-admin-panel && sudo bash deploy.sh
```
Скрипт сам: поставит бинарник, найдёт главный пароль (или спросит), создаст
самоподписанный TLS-сертификат, настроит службу `wdtt-admin`, откроет порт в
ufw/firewalld и выведет адрес и пароль входа.

Параметры: `--port 8443`, `--host dayzpe.fun`, `--main-password …`,
`--panel-password …`, `--uninstall`.

### Вариант 2 — с Windows по SSH
Запустите `deploy.bat`, ответьте на вопросы (адрес, пользователь, порт SSH,
ключ или пароль SSH). Нужен встроенный в Windows 10/11 «Клиент OpenSSH».
Всё передаётся в одном SSH-сеансе, пароли не остаются на диске.

## Использование
Откройте `https://ВАШ_СЕРВЕР:8443`. Браузер предупредит о самоподписанном
сертификате — это ожидаемо (можно подложить свой сертификат в
`/etc/wdtt-admin/cert.pem` и `key.pem` и перезапустить службу).

Вкладки: **Обзор** (нагрузка, трафик), **Клиенты** (создание, правка, срок,
отключение, отвязка устройства, смена пароля, удаление, ссылка `wdtt://`),
**Настройки** (DNS, лимит, порты, публичный адрес, очистка), **Копии**,
**Служба** (перезапуск, журнал), **Аккаунт** (пароль панели).

## Безопасность
- Вход по паролю (PBKDF2-SHA256), блокировка IP на 15 минут после 5 неудач.
- Сессия — подписанная cookie `HttpOnly; Secure; SameSite=Strict`, 12 часов;
  смена пароля сбрасывает все сессии. Защита от CSRF (заголовок + Origin),
  строгий CSP.
- Главный пароль WDTT хранится только в `/etc/wdtt-admin/config.json` (0600).
- Разрешён ограниченный список команд; перезапуск — отдельным действием.
- Рекомендуется ограничить доступ к порту панели по IP файрволом.

## Обслуживание
```bash
systemctl status wdtt-admin      journalctl -u wdtt-admin -f
wdtt-admin passwd                # сбросить пароль панели
wdtt-admin check                 # проверить связь с wdtt-server
```

## Сборка из исходников
`./build.sh` (Go 1.24+) пересоберёт `bin/wdtt-admin-linux-{amd64,arm64}`.
Исходники: `cmd/wdtt-admin/` (Go) и `cmd/wdtt-admin/ui/` (HTML/CSS/JS).
